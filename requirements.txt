# --- Model serving ---
#
# These are REQUIRED to serve. api/model.py imports them lazily inside the load
# path, so leaving them out does not crash the app — it starts, reports
# model_loaded=false on /health, and returns 503 from every analyse call. That
# failure looks like a missing artefact rather than a missing dependency, which
# is why it is called out here.
#
# On Linux, plain `pip install torch` pulls the CUDA build: ~2.5 GB of GPU
# kernels that a CPU server will never execute. Install the CPU wheel instead
# (~200 MB) — the Dockerfile does this explicitly:
#
#   pip install torch --index-url https://download.pytorch.org/whl/cpu
#
torch>=2.6
transformers>=5.0

# Declared explicitly even though transformers pulls it in. api/artifacts.py
# imports it directly to fetch the weights when artifacts/ is absent, which is
# the path a fresh clone takes — depending on it arriving as somebody else's
# transitive dependency means a transformers release could break model loading
# with an ImportError that names a package nobody chose to install.
huggingface_hub>=0.30

# --- Dev / test ---
# Installed in the Docker image too. `httpx` is small and FastAPI's TestClient
# needs it; `pytest` is ~5 MB and lets the container self-verify. Move both to a
# requirements-dev.txt if image size ever becomes a real constraint — it is not
# one at this stage, and being able to run the suite inside the image is worth
# more than the megabytes.
pytest>=8.0
httpx>=0.28
