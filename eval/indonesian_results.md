# Indonesian holdout — cross-language evaluation

Generated by `ml/evaluate_holdout.py` from `eval\indonesian_holdout.jsonl`.

**195 items** — 71 scam, 124 legitimate (36.4% scam).

This set was never trained on. The transformer was fine-tuned on EMSCAD,
which is English-language job-board text from 2017; this is a genuine
zero-shot cross-language test.

## How to read this

- **Prevalence floor: 0.3641.** A classifier that guesses randomly
  scores this on PR-AUC. Anything at or below it has learned nothing.
- **Length only: 0.3734** (clean — length carries no usable signal).
  This is the data-quality check. If it rises well above the prevalence
  floor, the two classes differ in length for reasons unrelated to fraud
  and every other number here becomes hard to interpret.
- **Model beyond length: +0.5524.** This is the honest measure of what the transformer contributes over the trivial baseline.

For reference on the training domain — TF-IDF on EMSCAD val: 0.8769 · transformer on EMSCAD val: 0.8763.

## Rule layer behaviour

- rules fired on scam items: 1.04 on average
- rules fired on legitimate items: 1.15 on average
- legitimate items triggering **any** rule: 117 / 124

That last line is the false-positive count the concept paper (section 3.6)
treats as the expensive error.

A rule that never fires contributes nothing on this data; one that fires
on almost everything is not discriminating.

- ECE **0.2952**, Brier **0.2705**

probabilities drift.
